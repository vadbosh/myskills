# Быстрый старт

Один экран. Полное руководство: [README.RU.md](README.RU.md) · [in English](FAST-START.md)

## Один раз

```bash
./install.sh --dry-run   # что изменится
./install.sh             # CLI, скил и хук во все найденные IDE
myskill list             # по строке на скил — значит работает
```

Перезапустите IDE: скилы и хуки читаются при старте.

## Дальше просто говорите ассистенту

| Вы говорите | Что происходит |
|---|---|
| `/myskill` | таблица: каждый скил и его состояние в каждой IDE |
| `что выключено` | `myskill list off` |
| `скрой от модели diagram` | `manual`: модель его не видит, `/diagram` по-прежнему работает |
| `отключи deploy` | `off` во всех трёх IDE |
| `включи diagram` | вернуть как было по умолчанию |
| `что зависит от notes` | хуки, правила и скилы, которые его называют |

В Codex скил вызывается как `$myskill`. В любом терминале CLI называется `myskill`.

## Состояния

| Состояние | Модель берёт сама | Вы вызываете | Claude Code | Codex | Opencode |
|---|:---:|:---:|---|---|---|
| `on` | ✅ | ✅ | `/name` | `$name` | `/name` |
| `manual` | ❌ | ✅ | `/name` | `$name` | `/name` или `/skills` |
| `off` | ❌ | ❌ | — | — | невозможно: становится `manual` |
| `·` | | | в этой IDE скил не установлен | | |

У скила плагина в Claude Code и Codex нет `manual`: он получает `off`.

## Если что-то не работает

```bash
myskill deps <name>     # off или manual не сработал: скил нужен этим строкам
myskill unusable        # скилы, которые здесь не заработают: нет переменной или программы
./release.sh check      # установленная копия отличается от этого клона
```

В текущей сессии изменение не видно. Начните новую.
